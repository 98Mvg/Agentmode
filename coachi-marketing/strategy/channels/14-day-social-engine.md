# 14-Day Social Engine

Use this as the theme bank and operating system for the next 14 days of Coachi social content.

The point is not to invent 14 separate content systems.
The point is to turn a limited Veo 3.1 budget into a repeatable cross-channel machine without overcommitting to 14 fixed execution days.

## Objective
Build a two-week content engine that:
- uses TikTok as the primary reach engine
- uses Instagram as the trust and conversion layer
- uses X as the learning-in-public layer
- uses Reddit as the reply-first authority layer
- respects the practical Veo 3.1 cap of `2 to 3` source videos per day

## Execution Rule
- Only the next `3` days are execution-locked at any time.
- Days `4 to 14` are a prioritized theme backlog.
- After each 3-day block, update the next block using:
  - the latest scorecards
  - the winner library
  - the Reddit language bank

## Core Rule
Treat Veo as the scarce upstream asset generator.
Everything else should be downstream packaging.

That means:
- do not generate a fresh Veo clip for every platform
- do not generate separate Veo clips for TikTok and Instagram by default
- generate one strong source clip, then make platform variants from it
- use the third daily Veo slot only as a recovery or bonus slot, not as the default plan

## Capacity Model
### Default daily content output
Every day, aim for:
- `1 to 2` TikTok videos
- `1` Instagram Reel
- `3 to 6` Instagram Stories
- `3` X posts
- `1 to 3` Reddit replies
- `0 or 1` Reddit post only if the angle is unusually strong

### Minimum viable daily output
Minimum viable day:
- `1` TikTok video
- `1` Instagram Reel
- `1 to 3` Instagram Stories
- `3` X posts
- `1` Reddit reply

### Stretch daily output
Stretch day:
- `2` TikTok videos
- `1` Instagram Reel
- `3 to 6` Stories
- `1` carousel if due
- `3` X posts plus full engagement loop
- `1 to 3` Reddit replies

### Default daily Veo allocation
Use this default cap:
- `1` primary Veo source clip
- `1` secondary Veo source clip only if the day needs a second angle
- `1` reserve slot for regeneration, rescue, or exceptional opportunity

Operational rule:
- do not spend all `3` Veo slots by default
- plan the day around `1` strong source clip and `1` optional backup
- if the first clip is clearly usable, keep the third slot unused

## Engine Structure
Every day runs through the same five layers:

1. one core runner tension
2. one hero short-form video angle
3. one Instagram trust packaging layer
4. one X learning layer
5. one Reddit reply pattern layer

## Channel Roles
### TikTok
Use for:
- interruption
- discovery
- emotional recognition
- comment bait

### Instagram
Use for:
- a cleaner Reel cut from the same source clip
- story follow-ups
- occasional carousel expansion every `2 to 3` days
- profile trust

### X
Use for:
- `2` founder/AI/building lessons tied to the topic
- `1` runner truth tied to the same pain

Required mix:
- `AI lesson`
- `shipping lesson`
- `runner truth`

### Reddit
Use for:
- answer real questions connected to the same daily theme
- mine runner language
- build trust without forcing links

Required pattern tags:
- `watch-checking anxiety`
- `heart-rate confusion`
- `Apple Watch interpretation`
- `Garmin interpretation`
- `beginner uncertainty`
- `easy-run pace drift`

## Asset Rule
One source clip should usually generate:
- `1` TikTok primary variant
- `1` TikTok alternate hook variant
- `1` Instagram Reel cut
- `3 to 6` story frames or repost story moments
- `1` caption question for comment bait
- `1` X runner-truth post seed
- `1` Reddit reply angle

Do not generate extra footage when packaging is the real bottleneck.

## Posting Rhythm
### TikTok
- post the primary daily clip first
- use the second TikTok slot only when:
  - the first hook is strong enough to justify a second test
  - the first clip underperforms early and the alternate hook is ready
  - the source clip is strong enough to support a second angle

### Instagram
- post one Reel per day from the strongest TikTok-ready source
- use Stories every day from the same theme
- use a carousel every `2 to 3` days only when the topic benefits from explanation

### X
Every day publish:
- `1` AI lesson
- `1` shipping lesson
- `1` runner truth

All three should connect to the same daily theme so the system compounds instead of fragmenting.

### Reddit
Every day:
- find `3 to 5` threads related to that day's theme
- reply to `1 to 3`
- keep the session reply-first
- do not force a new post unless the theme naturally invites discussion

## Daily Production Checklist
1. choose the day's theme from the calendar
2. decide whether the day needs `1` or `2` Veo source clips
3. write one Veo prompt and one backup prompt
4. generate the primary source clip
5. if the source works, stop generating and package it
6. render TikTok and Instagram variants from the same source
7. write the story pack from the same theme
8. write the `3` X posts from the same theme:
   - `AI lesson`
   - `shipping lesson`
   - `runner truth`
9. prepare Reddit reply angles using the same theme and pattern tags
10. log what performed best

## Daily Logging Rule
Track these every day:
- which Veo clip was generated
- whether the second or third Veo slot was used
- which TikTok hook won
- which Instagram Reel was posted
- whether a carousel was due and posted
- X type results:
  - strongest `AI lesson`
  - strongest `shipping lesson`
- strongest `runner truth`
- best Reddit thread pattern
- what to repeat tomorrow
- whether the day hit `minimum` or `stretch`
- what should be removed from the next 3-day block

## Decision Rules
If the day is overloaded:
- cut the second TikTok post before cutting the main Reel
- cut carousel work before cutting Stories
- cut a new Reddit post before cutting replies
- do not spend a third Veo slot just to feel productive

If a Veo clip fails:
- use the reserve slot once
- if the second attempt is still weak, reuse a stronger previous source clip and change the overlay/caption angle instead of brute-forcing more generations

If a topic performs:
- repeat the same tension with a sharper hook the next day
- do not change both the footage concept and the message at once

If the system feels overplanned:
- keep the 14-day theme direction
- rewrite only the next 3 days
- do not protect weak later-day ideas just because they are already on the calendar

## Best Use Of The Veo Limit
The limit is not a problem if the system is disciplined.

The winning structure is:
- `1` new source clip
- multiple hook treatments
- cross-channel packaging
- one clear learning loop

That is how you turn `2 to 3` Veo generations per day into a full 14-day social machine.
