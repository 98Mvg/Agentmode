# Daily Outputs

Daily marketing deliverables go here.

Minimum daily rollup:
- 3 X posts
- 1 TikTok idea
- 1 Instagram idea
- 1 audience insight
- 1 growth experiment
- 1 competitor observation
- 1 operational result note for what actually shipped
- 1 dated scorecard under `inputs/performance/`

## Required Social Tracking

Every dated social run note should include these sections.

### X Post Type Tracker
Log each published X post with:
- post number
- type:
  - `AI lesson`
  - `shipping lesson`
  - `runner truth`
- hook/topic
- URL
- link used: `yes` or `no`
- early note if visible

### Reddit Thread Pattern Tracker
Log each Reddit thread/reply touched with:
- subreddit
- pattern:
  - `watch-checking anxiety`
  - `heart-rate confusion`
  - `Apple Watch interpretation`
  - `Garmin interpretation`
  - `beginner uncertainty`
  - `easy-run pace drift`
- thread URL
- comment URL if posted
- reply angle
- curiosity/result note

### End-of-Run Read
Close every run with:
- strongest X type today
- weakest or missing X type today
- strongest Reddit thread pattern today
- one thing to repeat tomorrow

## Rolling Optimization Rule
Every 3 days, create one short optimization note using [ROLLING_3_DAY_OPTIMIZATION_TEMPLATE.md](/Volumes/Riot%20APFS/Agentmode/coachi-marketing/outputs/daily/ROLLING_3_DAY_OPTIMIZATION_TEMPLATE.md).

That note should answer:
- what won
- what underperformed
- what to repeat
- what to kill
- how the next 3-day block changes
