# 2026-03-31 X Session Learnings

## What Changed

We sharpened the Coachi X strategy away from generic runner posts and toward:
- build-in-public
- product truth
- shipping lessons
- early adopter trust

## Key Learning

Do not talk only about tech.

If a post only says:
- Swift
- Flask
- Xcode
- AI tooling

it attracts developers but not enough Coachi users.

For Coachi on X, every technical or build post must connect to:
- a runner problem
- a user benefit
- or a real shipping lesson

## Working Formula

Best X funnel:
- post
- curiosity
- profile click
- `coachi.no` / App Store

Best post shape:
- one sharp truth
- one real product/build detail
- one clear implication

## Stored Rule

Use X as the channel for:
- credibility
- early adopters
- feedback
- builder trust

Do not use it like broad motivational fitness content.

## Daily Operating Rule

Every day on X:
- 3 posts
- 10 follows
- 15 likes
- 1 repost
- 1 thoughtful reply

## Best Current Post Type

Build-in-public posts work best when they combine:
- AI-assisted building
- App Store friction
- product clarity lessons

Examples:
- got rejected 3 times
- had to ship `.v2` subscription IDs
- code worked, compliance failed
- the bug was comprehension, not implementation
