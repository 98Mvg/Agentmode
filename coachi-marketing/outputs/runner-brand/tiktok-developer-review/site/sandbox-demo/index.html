TikTok backend sandbox review flow

This review page demonstrates the complete end-to-end TikTok integration without exposing live tokens, secrets, or posting real content. The creator workspace calls backend sandbox endpoints that mirror TikTok creator_info, video.upload, video.publish, and status polling.

Login Kit user.info.basic

Used to display the connected creator nickname and account before any post action.

Content Posting API video.upload

Used when a creator chooses to upload original media as a TikTok draft for final editing.

Content Posting API video.publish

Used only after the creator reviews settings, gives consent, and chooses Direct Post.

Creator opens website
App icon is visible in the tab and header.
Creator signs in with TikTok
OAuth requests user.info.basic, video.upload, and video.publish.
TikTok redirects back
The app receives safe sandbox code and state values.
Backend loads creator info
/api/tiktok/sandbox/creator-info mirrors /v2/post/publish/creator_info/query/ before the post page renders.
Creator reviews post
The app shows creator info, privacy options, media preview, title, interactions, disclosure, and consent.
Creator chooses an action
The creator can upload a draft with video.upload or Direct Post with video.publish, then the app polls status.
