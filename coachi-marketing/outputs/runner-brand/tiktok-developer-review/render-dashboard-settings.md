# Render Static Site Settings

Use a Render Static Site, not a web service.

Render docs: static sites link a Git repo, deploy over CDN, receive an `onrender.com` URL, and can use custom domains.

## Dashboard Values

Name:

```text
everyday-runner-lab
```

Root Directory:

```text
coachi-marketing/outputs/runner-brand/tiktok-developer-review
```

Build Command:

```text
true
```

Publish Directory:

```text
site
```

Auto Deploy:

```text
No
```

## URLs After Deploy

Replace `<render-url>` with the URL Render gives you:

```text
https://<render-url>/
https://<render-url>/terms
https://<render-url>/privacy
```

Use those three in TikTok Developer until you have a custom runner-brand domain.

## Why Not Use Coachi.no

The TikTok app is for runner content publishing through Postiz, not for the Coachi app runtime. The review domain, demo video, and explanation should all match the runner-content use case.
