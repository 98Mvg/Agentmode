# Manual Photo Carousel Upload

Source pack: /Volumes/Riot APFS/Agentmode/coachi-marketing/content/slideshows/2026-05-30-why-heart-rate-spikes-slow
Output mode: photo_carousel
Slides: 7

## TikTok
1. Open TikTok Studio or TikTok mobile upload.
2. Choose Photos / Photo Mode, not video.
3. Select every file in ./slides in numeric order.
4. Paste tiktok-postiz-caption.txt if available, otherwise paste tiktok-caption.txt plus hashtags.txt.
5. Add TikTok Sound Library music: Light Music.
   Playlist: https://www.tiktok.com/tiktokstudio/sound-library/playlist/7413314027545168656
6. Review the order and press Post manually.

## Instagram
1. Create a new post and choose Select multiple.
2. Select every file in ./slides in numeric order.
3. Paste instagram-postiz-caption.txt if available, otherwise paste instagram-caption.txt plus hashtags.txt.
4. Review the carousel order and press Share manually.

## Guardrails
- Do not upload the MP4 for this flow.
- Keep the slide order numeric.
- Add music inside TikTok so the post remains a native photo carousel.
