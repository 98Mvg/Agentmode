## Visual Patterns To Reuse
- Veo-style blue-hour runner shot with one believable watch glance and lower-third text
- no-face founder-proof clip with the same runner identity but a visibly different scene recipe on every new video
- simple real-jog source prompts where the runner only jogs steadily and text + voiceover carry the story
- center or lower-middle white text with stroke/shadow; do not put the hook in the true bottom UI danger zone
- Q&A videos where the first screen asks one answerable runner question and the pinned comment collects follow-up inputs

## X Post Shapes To Reuse
- shipping lesson posts that explain what changed in the product decision and why the runner benefits
- person-led X sets where Coachi shows up in only `10 to 20%` of posts instead of every post
- quantified founder-proof posts: shipped updates, fixed real flaws, before/after product progress, concrete tool stack, and visible milestones
- posts that start from a real event before the lesson: `I shipped`, `I fixed`, `I cut`, `I tested`, `A user showed me`, `I learned this on a run`
- simple AI-builder posts that name the actual stack or workflow: Codex 5.5, Supabase, Render, Resend, ElevenLabs, App Store, watch app, backend, content engine

## Reddit Reply Shapes To Reuse
- watch-as-guardrail framing: useful when it protects the purpose of the run, risky when the number becomes a verdict
- calm answer first, then one practical nuance, then optional tool mention only if clearly earned
- Apple Watch interpretation replies that explain how to sanity-check the signal before panicking
- tension-and-breathing replies that start with body mechanics before discussing scary numbers
- Garmin interpretation replies that point out when the missing piece is recovery and truly easy aerobic work, not another hard session
- zone-control replies that define the run's success condition as restraint, not pace, then mention Coachi only as the quiet cue when effort drifts
- explicit app-discovery threads should follow the requested format first, then position Coachi as live feedback rather than another tracking/plans dashboard

## Losers To Stop Repeating
- product-forward X posts that read like landing-page copy before they read like founder learning
- abstract X posts that start with `signal`, `context`, `interpretation`, `arbitration`, `model`, or `data` without a concrete founder proof point first
- daily X sets where all 3 posts sound like the same product-theory paragraph in different words
- over-directed Veo source prompts that add gestures or behavior beats and make the gait look synthetic
- rerunning a live publishing day without a duplicate-post guard
- posting a second Instagram comment on a post where the account already has a visible prior comment
- forcing a second Reddit direct App Store link into the same low-volume run after one direct app-discovery comment has already posted
- posting a second TikTok comment on a post where the account already has a visible prior comment
- spending a live action on Instagram lead-magnet threads where nearly every comment is just the requested keyword
- reposting after a browser timeout before checking whether the first comment actually became visible
- public comments that improvise Coachi positioning instead of using the product description language, especially `coach-first, not another dashboard`
- repeating near-identical product-forward Instagram comments after a moderation removal notice
- placing Coachi into medical-risk high-heart-rate threads where the safer answer is to avoid product mentions
- interrupting creator lead-magnet keyword threads unless the post explicitly asks for alternatives or app recommendations
- publishing a main-account TikTok slideshow batch where most hooks are adjacent easy-run framings; rotate first-mile, recovery, Zone 2, heart-rate, watch-checking, comparison, and workout-control families before repeating easy-run language
