# Pinterest Asset Drop

Save the finished Pinterest picture here as:

`final-pinterest.png`

The upload script will classify that file as:

- bucket: `slideshow-public`
- platform: `pinterest`
- asset role: `pinterest_asset`

Recommended pin text:

`YOUR PACE IS LYING TO YOU`

Recommended size:

- `1000x1500`
- or any vertical `2:3` Pinterest-safe format
