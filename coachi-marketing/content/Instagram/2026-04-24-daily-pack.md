## Format
Reel

## Theme
Too much checking can make an easy run feel like an exam.

## Purpose
Recognition and calmer behavior change.

## Veo Plan
- same source concept as TikTok
- keep the Reel minimal and emotionally clear
- same runner identity, new cold forest-edge route, no-face over-shoulder angle

## Hook Options
- `STOP CHECKING THE WATCH`
- `THIS IS RUINING EASY RUNS`

## On-Screen Text Sequence
1. `STOP CHECKING THE WATCH`
2. `THIS IS RUINING EASY RUNS.`
3. `THE RUN STARTS FEELING LIKE AN EXAM.`

## Caption
This is one of the sneakiest ways to make an easy run feel worse.

Not because the numbers are terrible.
Because the checking gets constant.

Pace. Heart rate. Distance. Again. Again. Again.
And the run starts feeling like a test you can fail.

What do you check too often?
