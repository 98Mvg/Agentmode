# Instagram

Use this folder for feed captions, reel concepts, carousel copy, and story sets.

Instagram is the visual trust and conversion layer in the existing Coachi content system.

Default use:
- Reels for discovery and reach
- Carousels for saves and deeper education
- Stories for low-production engagement
- daily loop target:
  - `1` Reel
  - `3 to 6` Stories
  - `1` carousel every `2 to 3` days
  - `15` likes
  - `10` meaningful comments
  - `10` follows
  - `5` replies to comments or DMs

Rules:
- do not invent a separate Instagram ideation engine
- reuse the strongest TikTok source ideas
- keep the same face across related Instagram and TikTok organic assets
- use the shared organic runner anchor by default:
  - male, `25-35`
  - lean endurance-athlete build
  - short dark slightly textured hair
  - calm, focused expression
- save drafts with [OUTPUT_TEMPLATE.md](/Volumes/Riot%20APFS/Agentmode/coachi-marketing/content/Instagram/OUTPUT_TEMPLATE.md)
- use [instagram-content-system.md](/Volumes/Riot%20APFS/Agentmode/coachi-marketing/strategy/channels/instagram-content-system.md) as the canonical Instagram playbook
- rendered Reels should come from the shared video workflow in [generate_social_videos.py](/Volumes/Riot%20APFS/Agentmode/coachi-marketing/scripts/generate_social_videos.py), not a separate Instagram-only renderer
